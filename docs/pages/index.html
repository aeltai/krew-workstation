Krew Workstation

Kubectl plugin manager for Rancher Dashboard — terminal, plugins, files, and backups in one UI extension.

Extension Local dev Install & publish GitHub
This GitHub Pages site hosts documentation and the extension JavaScript bundle. The workstation UI itself runs inside Rancher Dashboard after you install the UIPlugin — not on this page.

Quick install (Rancher UIPlugin)

Point Rancher at the published bundle URL:

spec:
  plugin:
    name: krew
    version: "0.1.0"
    endpoint: "https://aeltai.github.io/krew-workstation/extensions/krew/0.1.0/plugin"

Verify the bundle is reachable:

  • package.json
  • krew-0.1.0.umd.min.js
